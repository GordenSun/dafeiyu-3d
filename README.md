# 大肥鱼 3D 互动小屋

在线玩：https://gordensun.github.io/dafeiyu-3d/

一个可以互动的 3D 大肥鱼网页：眼睛跟着鼠标转、会眨眼、17 种表情、23 段动作、4 套衣服、喂大白饭、扔沙滩球、召唤小金鱼，所有台词都有配音。

## 怎么做的

- **角色图**：GPT Image 2.6 按角色设定图出正面 A-pose 全身图；换装参考图用 Nano Banana 2.1 在同一张图上只改衣服颜色。
- **Tripo 3D（Studio MCP）**：
  - 图生 3D（HD v3.1，2K 贴图、去烘焙光照，约 3.8 万面）
  - 自动绑骨（biped）
  - 文生动作：7 个任务、最多 5 段一个任务，切成 23 段动作（打招呼、比心、跳舞、唱歌、哭、生气、被球砸……）
  - 按参考图重新贴图：圣诞装 / 夏日水手 / 魔法少女（UV 和原模型完全一致，网页里直接换贴图）
  - 文生 3D 道具：珊瑚舞台、大白饭、沙滩球、小金鱼
- **眼睛和嘴**：把贴图里画死的眼睛、嘴巴抹掉补成皮肤，网页里用 Canvas 实时画眼睛（追鼠标、眨眼、扫视、星星眼 / 爱心眼 / 蚊香眼……）和口型（跟着配音音量张嘴），作为同一个蒙皮网格的第二个材质组贴在脸上，跟着骨骼走。
- **动作重定向**：Tripo 文生动作用的是通用骨架，自己写了重定向（世界空间对齐 T-pose / A-pose 骨向、整圈转身保留、起止都朝前），合并进一个 GLB。
- **配音**：EdgeSpeak 本地合成（大肥鱼音色），52 句台词。
- **音乐 / 音效**：WebAudio 现场合成。
- **体积**：meshopt 压缩 + WebP 贴图，角色（含 23 段动作）约 1 MB。

## 本地运行

任意静态服务器，例如 `python3 -m http.server`，然后打开 `index.html`（`?debug=1` 显示点击区域，`?autostart=1` 跳过开始页）。
